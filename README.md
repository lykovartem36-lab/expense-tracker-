# Expense Tracker

**Автор: Лыков Артём

## Описание программы
«Expense Tracker» — это графическое приложение (GUI) на Python для отслеживания личных финансов. Программа позволяет добавлять расходы, присваивать им категории, сохранять историю в JSON-файл и анализировать траты за определенные периоды с помощью встроенных фильтров.

## Как использовать
1. Убедитесь, что у вас установлен Python версии 3.6 или выше.
2. Скачайте файлы проекта в одну папку.
3. Запустите программу через терминал или командную строку:
   ```bash
   python expense_tracker.py
